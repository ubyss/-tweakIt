# Toolsy

Toolsy reúne ferramentas rápidas para texto, dados, desenvolvimento, conversões, imagens, rede, matemática e mais em uma experiência bilíngue, limpa e centrada em busca.

## Princípios

- Busca independente do idioma da interface
- Processamento local por padrão
- Rotas compartilháveis para todas as ferramentas
- Catálogo central com metadados em PT-BR e EN
- Interface responsiva e acessível
- Dependências e carregamento inicial enxutos

## Desenvolvimento

```bash
npm install
npm run dev
```

## Validação

```bash
npm run typecheck
npm run lint
npm test
```

## Referência

O catálogo e alguns padrões funcionais foram estudados a partir do projeto [IT-Tools](https://github.com/CorentinTh/it-tools), licenciado sob GNU GPLv3. A implementação do Toolsy foi escrita de forma independente.
